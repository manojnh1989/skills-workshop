GitHub Copilot Skills

Learn what skills are, why they matter, how they compare with instruction files, and how to structure reusable skills inside a GitHub repository for GitHub Copilot.

What are Skills?

Skills are reusable knowledge modules that help GitHub Copilot understand how to perform specific tasks consistently.

  • Provide reusable domain knowledge
  • Guide Copilot with best practices
  • Standardize coding patterns
  • Improve consistency across repositories
  • Help generate better code suggestions

Why Skills?

Large projects often require common coding conventions, API standards, testing patterns, architecture rules, and framework-specific guidance.

Instead of repeatedly explaining these instructions in prompts, skills allow teams to centralize and reuse knowledge.

  • Reduces repetitive prompting
  • Improves developer productivity
  • Creates predictable AI-assisted code generation
  • Encapsulates project-specific expertise
  • Makes onboarding easier for new developers

Skills vs Instruction Files

Skills and instruction files are related, but they serve different purposes.

Instruction Files ----------------- - Mostly repository-wide guidance - Defines general behavior - Applies broadly across the project - Example: "Use Java 21" "Follow REST naming conventions" Skills ------ - Task-specific reusable knowledge - Focused on a capability or workflow - More modular and reusable - Example: "How to build Spring Boot REST APIs" "How to structure API exception handling"

Instruction files define broad repository behavior, while skills provide focused expertise for specific engineering tasks.

Benefits of Using Skills

  • Reusable engineering knowledge
  • Cleaner and more maintainable prompts
  • Better consistency in generated code
  • Project-specific AI guidance
  • Reduced manual review effort
  • Scalable AI-assisted development
  • Easy sharing across teams

Basic Skill Structure

A skill should be placed under the .github/skills directory so that GitHub Copilot can discover and understand it.

.github/ └── skills/ └── java-api-skill/ └── SKILL.md

Example simple skill:

# Java API Skill ## Purpose Help generate REST APIs using Spring Boot. ## Guidelines - Use Spring Boot REST controllers - Use constructor injection - Follow layered architecture - Return proper HTTP status codes - Use DTOs for API requests and responses ## Example @RestController @RequestMapping("/users") public class UserController { @GetMapping("/{id}") public UserDto getUser(@PathVariable Long id) { return userService.getUser(id); } }

Repository Placement

GitHub Copilot expects the skill inside the repository under:

.github/skills/java-api-skill/SKILL.md

Once placed correctly, Copilot can use the skill content to improve context-aware code generation and suggestions.
